วาง Web App URL ที่ได้จากการ Deploy ใน Google Apps Script

📋 ขั้นตอนติดตั้ง Google Apps Script (1 นาที):
  1. เปิดเว็บไซต์ script.google.com ➔ กด "+ โครงการใหม่" (New Project)
  2. กดปุ่ม "คัดลอกโค้ดสคริปต์" ด้านบน แล้วนำไปวางทับในหน้าเว็บ Apps Script ➔ กดบันทึก (💾)
  3. ที่มุมขวาบน กด การทำให้ใช้งานได้ (Deploy) ➔ การทำให้ใช้งานได้รายการใหม่ (New deployment)
  4. เลือกประเภทเป็น เว็บแอป (Web app) ➔ ตั้งค่า ผู้ที่มีสิทธิ์เข้าถึง เป็น ทุกคน (Anyone)
  5. กดทำให้ใช้งานได้ (Deploy) แล้วคัดลอก URL นำมาวางลงในช่องด้านบนนี้
